Music goes here!

Add your MP3 file and name it exactly:  music.mp3

(That means this folder should contain:  assets/music.mp3)

Recommended songs for a midnight-sky letter:
- "Until I Found You" – Stephen Sanchez
- "Die With A Smile" – Lady Gaga & Bruno Mars
- "Until You" – Gracie Abrams
- Any song that is "yours" as a couple 💗

Tips:
- Keep the file small (under 8 MB) so it loads fast on phones.
- If no music.mp3 is here, the website still works perfectly —
  the music button simply hides itself.
